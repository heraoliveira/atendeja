# Frontend AtendeJá

Este diretório receberá a aplicação React + TypeScript a partir da Fase 5.

Escopo planejado:

- React.
- TypeScript.
- React Router.
- React Hook Form.
- Cliente HTTP centralizado para integração com a API.
- Rotas protegidas por autenticação e roles.
- Interface em português PT-BR.

Nenhum código de frontend deve ser criado na Fase 0.
